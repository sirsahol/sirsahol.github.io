## Problem Statement & Background

Skilled Nigerian and African software engineers, designers, and knowledge workers face systemic friction discovering legitimate global remote opportunities. RemoteWorkNaija was built to curate, aggregate, and surface vetted international remote roles tailored for African professionals.

## Personal Role & Delivery Capacity

Sole Author and Full-Stack Developer (`SirSahOl`). Designed the full-stack architecture coupling a Python Django REST backend with a modern React client, job filtering pipelines, and automated scraping validation.

## Core Technical Constraints & Architectural Decisions

- Decoupled Client-Server Layout: Coupled a robust Python/Django API backend with a responsive React frontend.
- Curation & Scraping Guards: Designed validation logic to filter out spam job postings and invalid links.
- Data Structure Mapping: Persistent AST protocol and Graphify graph tracking at commit 4ac2ed4.

## Delivered System Topology & Technologies

Decoupled architecture: backend/ (Python/Django REST Framework) and my-app/ (React frontend) with persistent DSP maps.
